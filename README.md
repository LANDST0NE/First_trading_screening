# MOEX Trade Analyzer & Screener (T-Invest API)

Алгоритмический CLI-анализатор и скринер сделок (LONG / SHORT) для акций Московской Биржи (MOEX TQBR) на базе официального SDK Т-Инвестиций (`t-tech-investments`).

Система не использует примитивные индикаторные сигналы в вакууме («перепроданность по RSI — покупай»), а анализирует **рыночную структуру**: объёмный профиль VPVR (Point of Control), динамические поддержки/сопротивления EMA, локальные экстремумы (Swing High/Low) и волатильность ATR.

---

## Возможности

- **Запуск без ручной активации окружения:** удобные скрипты `scan.bat` и `scan.ps1`, которые автоматически находят `.venv`.
- **Поддержка режимов LONG и SHORT:**
  - Вход лесенкой (`50% + 50%`): первый вход на тесте локального объёма/EMA, второй — лимитный добор на откате.
  - Структурный якорь стопа (`Anchor_Stop`) за старшие скользящие (`4H_EMA50`) или профиль объёма (`1D_POC`), защищённый от ложных проколов буфером `0.6 * ATR_1H`.
  - Реалистичные свинговые тейк-профиты: Тейк 1 ($\ge 1.0 \times \text{Risk}$) на ближайшем препятствии и Тейк 2 ($2.0 \dots 4.0 \times \text{Risk}$) по старшей структуре.
- **Расчёт риска и лотности от рублёвого лимита:**
  - Депозит не запрашивается (работа с маржинальным плечом).
  - Учёт комиссии брокера `0.05%` за круг в расчёте R/R и финреза.
  - Адаптивный риск: при $R/R \ge 2.5$ — риск 1 750 ₽, при $1.8 \le R/R < 2.5$ — 1 000 ₽, при $R/R < 1.8$ — статус `SKIP` с расчётом точной цены лимитного входа `Ideal_Entry`.
- **Пакетный скрининг (`.\scan all`):**
  - Оценка 16 ликвидных акций Мосбиржи (`YDEX`, `SBER`, `GAZP`, `LKOH`, `NVTK`, `PLZL` и др.).
  - Учёт общерыночного фона индекса `IMOEX`.
  - Вывод сводной таблицы и детальных карточек **TOP-3 лучших бумаг дня**.
  - Фильтрация по направлению: `.\scan all long` и `.\scan all short`.
- **Автоматический экспорт отчётов:** чистый Markdown (`report_<TICKER>.md` и `screener_report.md`), готовый для копирования в LLM (Gemini / Claude) или торговый журнал.

## Быстрый старт

### 1. Клонирование и настройка
```bash
git clone https://github.com/LANDST0NE/First_trading_screening.git
cd First_trading_screening
```

### 2. Создание виртуального окружения и установка зависимостей
```bash
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. Настройка токена Т-Инвестиций
1. Получите токен с правами **«Только чтение»** в личном кабинете Т-Инвестиций (*Настройки -> Токены T-Invest API*).
2. Скопируйте шаблон конфигурации и укажите токен:
```bash
cp .env.example .env
```
В файле `.env`:
```ini
INVEST_TOKEN=t.your_token_here
```

## Команды запуска

Скрипты `scan.bat` и `scan.ps1` можно запускать напрямую из любого терминала (cmd или PowerShell) без ручной активации `.venv`:

- **Авто-анализ конкретной акции (определяет старший тренд и выбирает лучшее направление):**
  ```powershell
  .\scan NVTK
  ```
- **Принудительный расчёт направления (LONG или SHORT):**
  ```powershell
  .\scan NVTK long
  .\scan NVTK short
  ```
  *(Если направление идёт против тренда 1D/4H, выводится предупреждение `ВНИМАНИЕ: КОНТРТРЕНД ПРОТИВ 1D/4H`).*

- **Пакетный скрининг по тренду с отбором TOP-3 сделок дня:**
  ```powershell
  .\scan all
  ```

- **Пакетный отбор только лонг-идей по всем 16 акциям:**
  ```powershell
  .\scan all long
  ```

- **Пакетный отбор только шорт-идей по всем акциям:**
  ```powershell
  .\scan all short
  ```

- **Интерактивный терминальный режим:**
  ```powershell
  .\scan
  ```

## Структура проекта

```text
├── .env                  # Секретный токен API (в .gitignore)
├── .env.example          # Шаблон конфигурации
├── .gitignore            # Исключения git (секреты, venv, кэш, отчёты)
├── requirements.txt      # Зависимости проекта
├── README.md             # Документация
├── scan.bat              # Запуск из cmd / PowerShell
├── scan.ps1              # PowerShell-скрипт запуска
├── analyzer.py           # Главная точка входа и CLI-маршрутизатор
└── src/
    ├── __init__.py
    ├── config.py         # Константы, комиссии, тикеры MOEX
    ├── client.py         # Клиент T-Invest API (свечи 1H/4H/1D, проверка шорта, IMOEX)
    ├── indicators.py     # Расчёт EMA20/50, ATR(14) RMA, RSI(14) RMA, VPVR POC(80), Swings
    ├── strategy.py       # Торговая модель LONG/SHORT, свинговые коридоры тейков, лотность
    ├── reporting.py      # Вывод Rich-таблиц в терминал и экспорт в Markdown
    └── utils.py          # Округление до min_price_increment, форматирование цен
```
